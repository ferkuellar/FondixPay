# Phase 10C Requirements

## Goal

Implement the initial separate CRM Admin web frontend over Phase 10B backend admin APIs without weakening backend authorization or exposing sensitive payment/provider data.

## Included

- React/Vite/TypeScript `admin/` app.
- Permission-aware layout, navigation, dev access surface, API client, redaction utilities, and safe operational pages.
- Dashboard, users, payments, receipts, tickets, manual review, reconciliation placeholders, and audit logs.
- AXON-AI planning, documentation, backlog, validation, and completion artifacts.

## Excluded

- Mobile changes, real admin auth/MFA, real reconciliation, exports, role management, destructive ledger actions, real providers, real payments, and sensitive data rendering.
