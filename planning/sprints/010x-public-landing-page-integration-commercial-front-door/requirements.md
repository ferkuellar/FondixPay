# Phase 10X Requirements

## Goal

Integrate FondixPay's public landing page as an independent commercial front door without touching mobile, backend, CRM/Admin, payments, ledger, audit, receipts, Prontipagos, or card processor runtime.

## Requirements

- Inspect the delivered `FONDIX PAY Design System.zip`.
- Create a new `landing/` folder if none exists.
- Preserve the ZIP design as the visual source/base.
- Keep the landing static and separate from core transactional systems.
- Prepare Vercel-compatible static hosting.
- Add placeholders for pending public URLs.
- Document that Vercel is only approved for the public landing page.
- Update planning and documentation.
- Create a completion report.

## Explicit Non-Goals

- No mobile changes.
- No backend financial changes.
- No CRM/Admin changes.
- No real payments.
- No waitlist database.
- No secrets.
- No production claims.
