# Phase 6B Requirements

Implement demo-only account, balance, movement, and mobile display surfaces from the Phase 6A model.

Required outcomes:
- Protected account, balance, and movement reads for the current authenticated user.
- Demo account seed with integer MXN minor-unit amounts.
- Mobile balance and movement surfaces labeled as simulated and not real money.
- Backend tests and mobile typecheck recorded for the phase.

Out of scope: real wallet, real funding, withdrawals, banks, Prontipagos, KYC, reconciliation, and regulated claims.
