# Sprint 003 - UI/UX Production System Blueprint

## Proposed Work Order

1. Read `AGENTS.md`, `docs/UI_UX_GUIDELINES.md`, and this sprint.
2. Locate `fondix.png` in the repo or `references/`.
3. Audit current screens and theme tokens.
4. Define color, typography, spacing, radius, and component rules.
5. Build or refine reusable components.
6. Apply consistent layout to existing screens without changing business flow.
7. Add loading, empty, error, disabled, success, and pending-payment states where missing.
8. Validate on mobile viewport/device.
9. Run mobile typecheck.
10. Document any visual decisions in `planning/DECISIONS.md`.

## Candidate Components

- Screen container.
- Primary button.
- Secondary button.
- Input field.
- Service card.
- Payment summary.
- Receipt summary.
- Empty state.
- Error state.
- Loading state.

## Guardrails

Do not create new product features. Do not change payment semantics. Do not imply real payment readiness.
