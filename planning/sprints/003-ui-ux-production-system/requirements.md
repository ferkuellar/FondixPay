# Sprint 003 - UI/UX Production System Requirements

## Goal

Align the app visually with `fondix.png` and create a production-quality mobile UI/UX system.

## In Scope

- Theme definition.
- Spacing scale.
- Typography scale.
- Reusable components.
- Screen consistency.
- Loading states.
- Empty states.
- Error states.
- Success states.
- Disabled states.
- Pending payment state.
- Accessibility review.
- Android/iOS consistency.
- Mobile-first polish for the existing flow.

## Out of Scope

- Backend behavior changes.
- Real payments.
- KYC.
- New product modules.
- Admin console.
- Store publishing.

## Dependency

If `fondix.png` is not present, the sprint must first request or add the visual reference under the repo or `references/`.
