# Sprint 001 - AXON-AI Alignment Requirements

## Goal

Convert the existing FondixPay repository into a governed AXON-AI project without changing product behavior or implementation logic.

## In Scope

- Audit the current repo structure superficially.
- Preserve `mobile/` and `backend/`.
- Create `AGENTS.md`, `CLAUDE.md`, and `CODEX.md`.
- Create or update required `planning/` documents.
- Create or update required `docs/` documents.
- Document current mock/dev state.
- Document roadmap, risks, questions, domain, file inventory, and validation criteria.
- Prepare Sprint 002 and Sprint 003.

## Out of Scope

- New features.
- Real payment integration.
- KYC.
- Backend route changes.
- Mobile screen changes.
- Production hardening implementation.
- Secrets or real provider credentials.

## Constraints

- Do not delete or rewrite existing implementation.
- Do not declare production readiness.
- Do not treat the repo as empty.
- Durable decisions must go into `planning/DECISIONS.md`.
