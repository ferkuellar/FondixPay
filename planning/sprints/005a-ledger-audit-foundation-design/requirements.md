# Sprint 005A Requirements - Ledger & Audit Foundation Design

## Goal

Design the formal financial ledger, audit log, idempotency, traceability, payment state, provider transaction, reconciliation, and recovery foundation for FondixPay before any real payment provider integration.

## In Scope

- Ledger conceptual design.
- Audit event catalog and required fields.
- PaymentIntent, PaymentAttempt, ProviderTransaction, Receipt, LedgerEntry, and ReconciliationRecord relationships.
- Idempotency strategy.
- Payment state machine.
- Future Prontipagos preparation without integration.
- Future API contracts.
- Validation, security, and operations strategy.
- AXON-AI state, decision, risk, roadmap, and backlog updates.

## Out of Scope

- No Prontipagos integration.
- No real provider API calls.
- No credentials.
- No real money.
- No wallet.
- No production migrations.
- No mobile UI changes.
- No backend runtime changes.
- No admin console.
- No production readiness claim.

## Acceptance Summary

Sprint 005A is complete when design docs, sprint docs, backlog, ADRs, risks, and roadmap/state updates exist and real payments remain blocked.
