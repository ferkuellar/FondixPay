# Phase 10A Requirements

## Goal

Design the CRM Admin Panel architecture, RBAC, redaction, audit, support, reconciliation, and manual-review contract required before admin APIs or frontend implementation.

## Included

- CRM modules, workflows, production gates, future API and frontend architecture.
- Roles, permissions, data visibility, and prohibited actions.
- Admin audit event and proposed data-model additions.
- CRM backlog and AXON-AI sprint artifacts.

## Excluded

- Runtime code, admin endpoints, admin frontend, real roles in the database, admin login, provider integration, reconciliation execution, money movement, and destructive ledger changes.
