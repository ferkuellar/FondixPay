## FONDIXPAY Internal Escalation Path

When a Tekae-related support issue cannot be resolved by FONDIXPAY CRM staff:

1. CRM agent documents the issue in the internal ticketing system with Tekae transaction reference.
2. Escalate to FONDIXPAY operations lead.
3. Operations lead contacts Tekae support using contacts above.
4. Track resolution in internal ticket.
